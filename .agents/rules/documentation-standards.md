# Documentation Standards

1. **Living Documentation Suite**: Maintain and synchronize the following canonical documents in `docs/`:
   - `docs/PROJECT_STATUS.md`
   - `docs/ARCHITECTURE.md`
   - `docs/DATABASE_SCHEMA.md`
   - `docs/API_DOCUMENTATION.md`
   - `docs/INTEGRATIONS.md`
   - `docs/DEVELOPMENT_ROADMAP.md`
   - `docs/KNOWN_ISSUES.md`
2. **GSD State Tracking**: Keep `SPEC.md` and `STATE.md` at the repository root updated after every task and phase milestone.
3. **Milestone Updates**: At the conclusion of every development increment, record completed functionality, created/modified files, empirical test results, known issues, and the exact next task in `docs/PROJECT_STATUS.md` and `STATE.md`.
